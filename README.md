# 罗政豪 · 个人作品集网站

一个使用**原生 HTML、CSS、JavaScript** 构建的杂志式（Editorial）个人作品集网站。全程不使用 React / Vue 等前端框架，不引入任何第三方 UI 组件库，无构建工具、无运行时依赖。

## 项目简介

网站以「暖纸 + 墨 + 朱砂红」的纸媒排版语言为主视觉，通过巨型水印字母、四角刻标、竖向标注、切角标签等编辑式细节，展示个人介绍、精选项目作品与联系方式。项目作品区采用数据驱动渲染，新增作品只需追加一条数据。

## 功能特性

- **杂志式排版**：分区巨型序号水印、四角刻度线、竖向标注文字、斜切强调色带
- **深浅色主题切换**：导航栏右侧按钮一键切换，选择保存在 `localStorage`，刷新后保持
- **数据驱动的作品区**：作品数据与视图分离，支持 4 种排版布局自动适配
- **响应式设计**：同时兼容桌面端与移动端，移动端提供汉堡菜单
- **轻量无依赖**：纯原生实现，克隆后开箱即用

## 本地运行

项目为纯静态页面，无需安装任何依赖。

**方式一：直接打开**

双击 `index.html` 即可预览。

**方式二：本地静态服务器（推荐）**

```bash
cd portfolio
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

> 主题偏好依赖 `localStorage`，部分浏览器在 `file://` 协议下会对其做限制；如需完整验证主题记忆功能，建议使用方式二。

## 主题切换

- 通过给 `<html>` 设置 `data-theme="light" | "dark"` 切换整套 CSS 变量
- 浅色与深色主题反转「纸 / 墨」配色，并同步调整导航栏底色、水印字色、分隔线、反相色块上的文字
- 用户选择写入 `localStorage` 的 `portfolio-theme` 键；首次访问默认浅色
- 为保证对比度，强调色块（朱砂红背景）之上的文字始终使用深色

## 项目作品区

作品数据集中维护在 `js/projects.js` 的 `projects` 数组中，页面对其遍历渲染。新增作品只需追加一条数据：

| 字段 | 说明 |
| --- | --- |
| `id` | 编号，用于序号与水印 |
| `layout` | 布局模式：`split-left` / `split-right` / `full` / `offset` |
| `genre` | 类别眉题 |
| `tag` | 小号类别标签 |
| `title` | 作品名称 |
| `desc` | 一句话简介 |
| `date` | 完成时间 |
| `category` | 信息分类（用于信息网格） |
| `stack` | 技术栈数组 |
| `images` | 图片数组（1 张或 2 张） |

四种布局模式：

- `split-left` — 左图右文（大图 7/12）
- `split-right` — 右图左文（镜像节奏）
- `full` — 全宽大图 + 底部信息带（大字报感）
- `offset` — 错落双图 + 局部色块标题（编辑排版感）

## 响应式断点

| 断点 | 调整内容 |
| --- | --- |
| `900px` | 作品区回落为单列排版，取消错落与色块偏移 |
| `860px` | 导航折叠为汉堡菜单，隐藏竖向标注文字 |
| `560px` | 首屏高度自适应，收紧大标题字号 |

## 开发约定

- 使用原生 HTML / CSS / JavaScript，不引入框架与第三方 UI 组件库
- HTML、CSS、JavaScript 分别放在各自文件中
- 页面需同时兼容桌面端与移动端
- 修改后需在浏览器中实际验证，且不得破坏已有功能
